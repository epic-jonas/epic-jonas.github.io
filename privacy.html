Privacy policy

Effective date: 14 October 2026.

This policy describes a personal rclone configuration intended solely for the account owner's use.

Access and purpose

Rclone accesses file contents and metadata in the owner's Google Drive to browse and transfer files between Drive and the owner's computer, and to perform file operations requested by the owner. Read/write authorization can permit uploads, modifications, renaming, and deletion.

Storage and transmission

Google Drive stores the cloud files. Rclone runs on the owner's computer and communicates with Google's authentication and Drive services. OAuth configuration and authorization tokens are stored locally with access restricted to the owner's Linux account. Downloaded files and cached file content may also be stored locally. Operational logs may contain file names and transfer information.

This public information website does not receive Google Drive files, OAuth credentials, or authorization tokens. It contains no forms, application scripts, or added analytics. It is hosted by GitHub Pages; GitHub may collect website request information, including visitor IP addresses, under the GitHub Privacy Statement.

Sharing and control

This configuration does not sell Google user data or intentionally send it to advertising or analytics services. File operations requested by the owner can change what is stored in Google Drive. Any separate sharing or processing of files by the owner is outside the operation described here.

The owner can stop the local rclone service and revoke its authorization in Google Account connections. Revoking authorization prevents further authorized access; it does not automatically remove files or cache data already stored locally. Local copies, caches, and the rclone configuration can be removed separately when no uploads remain pending.

Google API data

Use of information received from Google APIs will comply with the Google API Services User Data Policy, including its Limited Use requirements.

Contact and updates

The configuration is operated by its sole user. The support contact is the owner's email address shown in its Google OAuth consent configuration. This policy will be updated if the configuration's data practices change.
