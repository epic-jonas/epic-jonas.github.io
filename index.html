Personal desktop configuration

Omarchy Google Drive

Access to the owner's Google Drive files from a Linux computer, using rclone.

Purpose

Omarchy Google Drive is a personal configuration of rclone on Omarchy Linux. It is operated by its sole user and is not offered as a service to other users.

The connection supports browsing, downloading, uploading, renaming, and deleting files according to the permissions granted by the account owner. Local caching supports opening and saving files in desktop applications.

How it connects

Rclone runs on the owner's computer and connects directly to Google's authentication and Drive services. The account owner authorizes access through Google. OAuth configuration, authorization tokens, and cached file content are stored locally.

This website provides information about that configuration. It does not provide sign-in, receive Drive credentials, or host Drive files.

About this configuration

This is not an official Google or Omarchy product. The support contact is the owner's email address shown in the Google OAuth consent configuration.
